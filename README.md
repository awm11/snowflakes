# Grow a Snowflake

An interactive snowflake growth simulation for students. It's a single self-contained `index.html` with no dependencies.

- **Grow tab:** steer temperature and humidity with the sliders or by dragging the point on the Nakaya morphology diagram (or press *Auto-drift*), and watch the crystal grow on a hexagonal grid (a Gravner–Griffeath-style vapour diffusion model). A side view shows plate vs column habit. You can colour the ice by the temperature or time at which it formed.
- **Paper snowflake tab:** turns the grown crystal into a simplified, printable 30° cutting template for a six-point folded paper snowflake, with folding instructions and a preview.
